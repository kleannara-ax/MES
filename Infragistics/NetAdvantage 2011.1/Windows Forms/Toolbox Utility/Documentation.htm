Infragistics® Toolbox Utility

  
 

About the utility

The purpose of the Toolbox Utility is to automate the process of creating tabs containing the Infragistics controls in the Visual Studio toolbox. The utility will create tabs for a specific product, version, and CLR of the Infragistics controls for a specific version of Visual Studio. The utility will search for the Bin folders that contain the assemblies for the product being installed, and then follow a template to determine what tabs to create and what assemblies are added to each tab.

Requirements and Supported Environments

The .NET Framework version 2.0.50727 or higher must be installed for the utility to function.

Command line options

Command line options:

/?
        Brings up the help menu

/u
        Indicates to remove the tabs based on the template used.

/prompt
        Prompts the user to hit a key before the application finishes.

/target:<Visual Studio Target>
        The target of Visual Studio to create the toolbox for.  If this option is not set, all installed versions will be targeted.
        Example: /target:9.0

/productname:<Product Name>
        The type of product being installed.
        Example: /productname:win

/clr:<CLR>
        The CLR version of the product being installed.
        Example: /clr:CLR20

/template:<Path to template>
        The template to follow when creating or removing tabs.
        Example: /template:"Templates\MyTemplate.xml"

/config:<Path to config>
        A configuration file that contains settings to run the toolbox.
        Example: /config:"Config Files\InstallMyTools.xml"

/binfolder:<Path to assemblies>
        Optional semi-colon deliminated list of paths to the folders the assemblies are in.
        Example: /binfolder:"C:\bin1";"C:\bin2"

/productversion:<ProductVersion>
        The version of the product being installed.
        Example: /productversion:9.2

How to run from a configuration file

The information to create the toolbox tabs can be loaded from a configuration file using the /config command line switch. This can allow multiple products and versions to be installed with one run of the utility.  Each time that the utility is used to create or remove tabs, a configuration file is generated in "My Documents\Infragistics\Tools\Toolbox Utility\CommandLine Settings". The last 10 runs of the utility will be saved in this folder.

Example:
This example will install the Windows Forms 9.2 CLR 2.0 controls into Visual Studio 2005. It will install the assemblies found in the BinFolder location and use the "WinForms" template found in the Templates subfolder of the utility.

<CommandLineSettings>
        <Product Name="Win" CLR="CLR20" Volume="9.2" VisualStudioVersion="8.0" Template="Templates\WinForms.xml">
                <BinFolder>C:\Program Files\Infragistics\NetAdvantage 2009.2\Windows Forms\Bin</BinFolder>
        </Product>
</CommandLineSettings>
